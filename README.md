# 기사단 방치기 (Idle Knight RPG)

갤럭시 Z 플립6 (Android 16 / 22:9 세로 화면)에 최적화된 웹 + Capacitor 기반 중세 판타지 자동 사냥 방치형 RPG 프로토타입입니다.

## 주요 명령어

```bash
# 개발 서버 실행 (PC 브라우저)
npm run dev

# 모바일 Wi-Fi 테스트용 서버 실행 (플립6 크롬에서 Network 주소 접속)
npm run dev:mobile

# 단위 테스트 실행
npm test

# 타입 체크 + 프로덕션 빌드
npm run build
```

자세한 Google Flow 에셋 교체 규약 및 Android APK 빌드 방법은 [ASSETS_GUIDE.md](./ASSETS_GUIDE.md)를 참고하세요.
